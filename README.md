# NierUI

Библиотека меню в стиле NieR:Automata для Roblox-скриптов.

Без внешних зависимостей и без единого ассета: шрифт берётся встроенный,
палитра собрана из градиентов, фактура фона рисуется процедурно в рантайме.
Грузить нечего, модерировать нечего, перестать открываться нечему.

---

## Подключение

Публиковать нужно `dist/NierUI.luau` — это вся библиотека одним файлом.

```lua
local NierUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ/main/dist/NierUI.luau"
))()
```

Файлы в `NierUI/` — исходники. Сборка одним файлом делается `build.ps1`.

| витрина | что показывает |
|---|---|
| `dist/NierUIDemo.luau` | все элементы разом |
| `dist/BindDemo.luau` | только ядро привязок |

Обе запускаются как есть и убирают за собой прошлый запуск.

## Минимальный пример

```lua
local win = NierUI:Window({
    Title = "MY SCRIPT",
    Subtitle = "v1.0",
    ConfigFolder = "myscript",
})

local tab = win:Tab("MAIN")

tab:Toggle({
    Text = "ПОЛЁТ",
    Desc = "Летать по клавише.",
    Flag = "fly",
    Bind = true,                          -- клавишу назначит человек в меню
    Callback = function(on) fly(on) end,
})

tab:Slider({
    Text = "СКОРОСТЬ",
    Min = 16, Max = 200, Default = 60,
    Flag = "flySpeed",
    Callback = function(v) speed = v end,
})
```

Три строки — и это уже фича с клавишей, которая правится в игре и переживает
перезапуск в профиле.

## Три вещи, которые стоит знать сразу

**Ни одного опроса и ни одного `task.spawn`.** Всё на событиях, анимация на
`TweenService`, каждая подписка записана и гаснет в `Destroy`. Единственное
исключение — счётчик кадров: их нельзя посчитать иначе, чем считая кадры, и его
подписка живёт, только пока он показан. Подробнее — в
[инвариантах](docs/internals.md).

Обычные циклы, разумеется, есть — подъём по дереву при проверке попадания и
перебор слов в поиске. Речь о другом: нет ни одного цикла, который **ждёт** и
переживает вызов.

**Клавиша, режим и подпись привязки принадлежат человеку за меню, а не
скриптеру.** Скрипт говорит, ЧТО делать; всё остальное настраивается в игре и
уезжает в профиль. Ничего из этого библиотека при объявлении не требует —
`Bind = true` достаточно. См. [привязки](docs/binds.md).

**Молчание — худший исход, поэтому библиотека ругается вслух.** Занятый `Flag`,
`Menu` вместе с `Settings`, `Bind` у виджета, который его не разбирает,
настройка со значением, из которого контрол не выводится, спорная клетка блока —
всё это ошибки при постройке, а не пустая строка в меню, которую можно объяснить
только сверившись с кодом.

## Папка конфигов задаётся вызывающим

```lua
NierUI:Window({ Title = "MY SCRIPT", ConfigFolder = "myscript" })
```

Без неё `Save` и `Load` бросают явную ошибку. Библиотека намеренно не выводит
имя папки из заголовка окна: заголовок меняется по вкусу, и каждая его правка
оставляла бы на диске новую папку с осиротевшими профилями.

---

## Скрипт, который перезапускают, снимает прошлое окно сам

```lua
if getgenv().__myWindow then getgenv().__myWindow:Destroy() end
getgenv().__myWindow = win
```

Иначе они накопятся стопкой, и щелчок будет доходить только до верхнего.
