# Экран: уведомления, худ, диалоги

То, что видно поверх игры: уведомления, постоянные слои (счётчик кадров,
список привязок) и модальное подтверждение.

## Уведомления

```lua
win:Notify({ Title = "PLAYER", Text = "Кто-то зашёл", Duration = 6 })
```

Выезжают из-за правого края, стопкой, снизу убывающая полоска остатка. Живут на
`ScreenGui` рядом с окном, поэтому **показываются и при закрытом меню**.

## Худ

```lua
local fps   = win:FpsCounter({ X = 24, Y = 90 })
local binds = win:BindList({ X = 24, Y = 130, Title = "KEYBINDS", Mode = "all" })
local hud   = win:Hud({ Title = "STATS", X = 24, Y = 260 })   -- свой, под что угодно

fps:SetVisible(false)
binds:SetMode("active")   -- :GetMode() :Refresh() :IsVisible() :Destroy()
```

| поле | у кого | что значит |
|---|---|---|
| `X`, `Y` | у всех | где поставить; зажимается по экрану |
| `Title` | у всех | полоса заголовка; без неё слой без шапки |
| `Width` | у всех | ширина слоя |
| `Visible` | у всех | завести спрятанным |
| `Transparency` | у всех | прозрачность подложки |
| `Flag`, `Save` | у всех | положение в профиль |
| `TextSize` | `FpsCounter`, `BindList` | размер подписи |
| `Mode`, `Empty`, `NameMax` | `BindList` | режим показа, текст пустого списка, предел длины имени |

Живут на `ScreenGui` рядом с окном, поэтому **показываются при закрытом меню** —
как и уведомления. Перетаскиваются мышью.

**Положение идёт в профиль** — дайте худу `Flag`:

```lua
win:FpsCounter({ X = 24, Y = 90, Flag = "hudFpsAt" })
```

Место в углу экрана человек выбирает один раз, и заново двигать слой после
каждого перезапуска незачем. Видимостью худ при этом **не** заведует: ею почти
всегда управляет отдельный тумблер вызывающего, у него свой `Flag`, а два
хозяина у одного значения означали бы, что при загрузке побеждает тот, кого
профиль применил последним — а порядок обхода профиля не определён.

`Hud` — обычный контейнер, в него кладутся любые виджеты.

**Взаимодействие только при открытом меню.** Закрыли — перехват ввода снят,
своего указателя нет, и попасть по слою нечем. Для счётчика и списка привязок
это ровно то, что нужно: они показывают, а не принимают.

### Счётчик кадров

Подпись вида `FPS: 143.2`. Число сглажено по окну: мгновенное `1/dt` скачет на
десятки даже при ровной картинке, и десятая доля у него ничего не значила бы.

### Список привязок

| режим | что показывает |
|---|---|
| `"all"` | все привязки, каждая с пометкой `[ON]` или `[OFF]` |
| `"active"` | только включённые |

Строка списка — три колонки: имя, режим, клавиша с состоянием.

```
ЛЕТАТЬ    [T]      H[ON]
ПРИЦЕЛ    [H]     C[OFF]
ОТДАЧА У..[T]     T[OFF]
ФОНАРЬ    [B]          F
```

**Имя обрезается на восьми символах**, дальше многоточие: слой висит поверх игры
и место отнимает у неё, а не у меню. Предел правится — `NameMax`; размер шрифта
— `TextSize`, ширина — `Width`.

Считаются именно символы, а не байты: в UTF-8 кириллическая буква занимает два,
и обрезка по длине строки разрубила бы восьмую букву пополам.

| пометка | режим |
|---|---|
| `[T]` | `ПЕРЕКЛ.` — нажал и отпустил |
| `[H]` | `ЗАЖАТИЕ` — работает, пока держишь |
| `[B]` | действие — сработало и всё |

**Что считается включённым — отвечает сама привязка**, одним вызовом `Get`.
Прежде состояние выводилось из разметки: список искал строку-владельца по
контейнеру, в котором привязка объявлена. Отсюда бралась главная ложь этого
экрана — у тумблера `ПОЛЁТ` спрашивалось «включён ли он», а показать надо было
«летим ли мы». Ни владельцев, ни `State`, ни запасных вариантов больше нет.

Показываются только привязки **с клавишей**: без неё нажимать нечего. Убрать из
списка привязку с клавишей может человек — правой кнопкой в менеджере; скриптеру
этого поля не выдано, чужой экран не его забота.

Список **прокручивается**: высота слоя зажата экраном, и три десятка привязок
не обрезаются.

## Модальное подтверждение

```lua
win:Confirm({
    Title = "UNLOAD", Text = "Снять меню целиком?",
    Confirm = "YES", Cancel = "NO",
    OnConfirm = function() win:Destroy() end,
})
```
