# Тема

Палитра, шрифт, размеры и фактура. Меняется до создания окна.

Меняется **до** создания окна: значения читаются в момент постройки.

```lua
NierUI.Theme.Font = Enum.Font.RobotoMono
NierUI.Theme.Bg   = Color3.fromRGB(207, 201, 176)
NierUI.Theme.Ink  = Color3.fromRGB(69, 65, 56)
```

| цвета | |
|---|---|
| `Bg` | песочный фон |
| `BgSunk` | утопленный: раскрытые блоки |
| `Ink` | чернила |
| `InkSoft` | второстепенный текст |
| `Disabled` | недоступное; бледнее второстепенного |
| `Font` | шрифт |

| размеры | |
|---|---|
| `WindowWidth` `WindowHeight` | 644 × 483 |
| `HeaderHeight` `HintHeight` `TabColumnWidth` | шапка, нижняя панель, колонка вкладок |
| `PopupTitleHeight` | полоса заголовка всплывающего окна |
| `RowHeight` `TextSize` `TitleSize` | строка и текст |
| `DropdownMax` | сколько пунктов видно до прокрутки |

Шапка, колонка вкладок и нижняя панель заданы **в пикселях намеренно**: они не
должны расти вместе с окном, иначе на большом меню шапка становится вывеской.

| раскладка строки | |
|---|---|
| `LabelFrac` | докуда идёт подпись — 0.40 |
| `TrackRight` `TrackFrac` | правый край и ширина дорожки — 0.70 и 0.22 |
| `ValueFrac` | ширина значения — 0.24 |

Всё, что стоит в строке справа, задано **долями ширины, а не пикселями**. Раньше
это были жёсткие отступы от правого края, и они работали при полной ширине
страницы, но в половинной ячейке блока отступ уходил за левый край — дорожка
ложилась поверх подписи. Доли рассчитаны так, чтобы зоны не пересекались ни при
395 пикселях, ни при 190.

| поверхность | |
|---|---|
| `Scanlines` `ScanStep` `ScanAlpha` | скан-линии |
| `Grain` | разброс альфы зерна, 0..255 |
| `GridStep` `GridAlpha` | миллиметровка; из-за неё фон читается как бумага |
| `Band` `BandHeight` | полосы-перфорации сверху и снизу |

| прочее | |
|---|---|
| `BlockGap` `BlockTitleHeight` `BlockSeparators` | блоки |
| `NotifyWidth` `NotifyDuration` | уведомления |

Шрифт по умолчанию — `Merriweather`, ближайшая к оригиналу антиква из
встроенных; кириллицу держит (проверено на экране). Подбор идёт **с откатом**:
нет шрифта в клиенте — спускаемся по списку `Merriweather → Bodoni → Garamond →
SourceSans`, а не падаем с ошибкой.
